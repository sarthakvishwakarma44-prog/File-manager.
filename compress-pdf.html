Frequently asked questions

Why can I not select text after compressing?

To shrink the file, each page is saved as an image. This works best for scans and photo-heavy PDFs.

Which level should I choose?

Start with Medium. Use Strong if the file is still too big, or Light if quality matters most.

Why did it say my PDF is already small?

If the result would not be smaller than the original, we do not offer it. Keep the original or try Strong.
