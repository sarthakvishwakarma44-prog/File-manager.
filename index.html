    How to merge PDF files online

    1. Click Choose PDF files or drag your PDFs into the box. You can select many files at once and add more later with Add more files.
    2. Check the list. Each row shows the file name, the number of pages and the file size, so you can spot a wrong file quickly.
    3. Drag a file up or down to change its position. The file at the top becomes the first pages of the merged document.
    4. Click Merge PDFs. For normal documents it takes a few seconds.
    5. Click the download button to save merged.pdf to your phone or computer.

    When do you need to merge PDFs?

    Many websites and offices accept only one file per upload. Combining your documents into a single PDF keeps everything together and in the right order. Common situations include:

    • Job and college applications: a resume, cover letter, certificates and ID in one file.
    • Invoices and receipts: a month of bills combined for an expense report or tax filing.
    • School work: several chapters or assignments sent as one document.
    • Scanned pages: phone scanner apps often save each page separately, and merging joins them into one document.
    • Contracts and legal papers: the agreement and all its attachments in one place.

    Tips for a clean result

    Check the order before merging

    It is much faster to fix the order in the list than to rearrange pages afterwards. Name your files with numbers, such as 01-resume.pdf and 02-certificate.pdf, so they are easy to recognise.

    Mixed page sizes are normal

    If one file uses A4 pages and another uses Letter pages, each page keeps its own size. The merged file will contain both, which is fine for viewing and printing.

    Large files

    The merge happens on your own device, so very large files depend on your available memory. If a merge fails, try merging fewer files at a time, or compress the biggest file first with our Compress PDF tool.

    Your files stay private

    This tool does not upload anything. Your PDFs are read and combined inside your web browser, and the result is created on your device. Nothing is sent to our servers, so it is suitable for personal and confidential documents. When you close or refresh the page, the files are gone from memory.

    Common problems and fixes

    • "Could not read" message: the file is damaged or protected with a password. Remove the password in your PDF viewer, save a copy, and try again.
    • The merge button is grey: you need at least two PDF files in the list.
    • A file was skipped: only files with the .pdf extension are accepted. Convert images with our Image to PDF tool first.
    • Bookmarks or form fields are missing: the tool copies the pages themselves, so document-level extras may not carry over.

    Frequently asked questions

    Is it safe to merge confidential PDFs here?

    Yes. The merge happens inside your browser, so your documents are never sent to a server.

    Is there a limit on file size or number of files?

    There is no fixed limit. Very large files depend on your device's memory, so merge in smaller groups if you see an error.

    Will the quality of my pages change?

    No. Pages are copied as they are, so text stays sharp and selectable and images are not re-compressed.

    Can I merge password-protected PDFs?

    No. Remove the password first, then merge the files.

    Does it work on a phone?

    Yes. It works in modern mobile browsers. Reordering by dragging can be awkward on small screens, so choose the files in the order you want.

    Do I need to create an account?

    No. There is no sign-up, no watermark and no fee.
