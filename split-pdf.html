How to split a PDF online

  1. Click Choose PDF file or drag one PDF into the box. The page shows its name, page count and size.
  2. Pick a mode. Extract pages creates one new PDF that contains only the pages you list. Split every page creates one PDF per page, delivered as a ZIP file.
  3. For extraction, type the pages you want, for example 1-3, 5, 8-10.
  4. Click Split PDF and download your file.

How to write page ranges

Separate items with commas and use a dash for a range. For a 12-page document:

  • 1-3 gives pages 1, 2 and 3.
  • 2, 7, 11 gives only those three pages.
  • 1-3, 5, 8-10 gives pages 1, 2, 3, 5, 8, 9 and 10.

Pages come out in the order you type them, so 5, 1 puts page 5 before page 1. If a number is outside the document, the tool tells you the allowed range instead of failing.

When is splitting useful?

  • Sending only what is needed: share one chapter, one invoice or one signed page instead of the whole file.
  • Removing pages: extract everything except the pages you do not want, such as blank or private pages.
  • Reducing file size: email a smaller part when the whole document is too large for an attachment.
  • Separating a scan: a scanner that saved ten receipts in one PDF can be split into ten files.
  • Reordering: extract pages in a new order, then merge them with other files.

What you get when you split every page

The tool creates a ZIP file that holds one PDF for each page. The files are named after your original document with the page number added, for example report-page-01.pdf, report-page-02.pdf and so on, so they stay in order when sorted. Open the ZIP on your device to use the files.

Privacy

Splitting happens inside your browser. Your PDF is not uploaded to any server, and the new files are created on your own device.

Frequently asked questions

Can I split a password-protected PDF?

No. Remove the password first in your PDF viewer, save a copy, and then split that copy.

Does splitting reduce quality?

No. The selected pages are copied exactly as they are, so text and images stay the same.

Can I extract pages from different parts of the document?

Yes. Use commas, for example 1-2, 6, 9-12. All of them go into one new PDF.

Is my original file changed?

No. Your original file is untouched. The tool only creates new files.

Why did I get an error about the page range?

A number may be outside the document or typed in an unsupported way. Use only digits, commas and dashes, such as 1-3, 5.
